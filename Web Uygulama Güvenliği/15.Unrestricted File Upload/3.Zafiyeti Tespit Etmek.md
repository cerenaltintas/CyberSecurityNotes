Unrestricted File Upload zafiyetini tespit etmenin ilk adımı, dosya yükleme işleminin doğru şekilde sınırlandırılıp sınırlandırılmadığını kontrol etmektir. Aşağıdaki belirtiler, bir dosya yükleme işlevinin güvenli olmadığını gösterebilir:

- Dosya türü kontrolü yapılmıyor veya yetersiz yapılıyor.
- Yüklenen dosya adlarında ve yollarında tehlikeli karakterler bulunabiliyor.
- Dosya boyutu kontrolleri eksik veya tamamen yok.
- Yüklenen dosyalar doğrudan erişilebilir ve çalıştırılabilir durumda.

### Test Yöntemleri

Zafiyeti tespit etmek için çeşitli test yöntemleri kullanılabilir:

1. **Dosya Türü Kontrolü**
    
    - Farklı türde dosyalar yüklemeyi denemek (örneğin, 
        
        .jpg
        
        , 
        
        .php
        
        , 
        
        .asp
        
        , 
        
        .exe
        
        ).
    - Sunucunun bu dosyaları kabul edip etmediğini kontrol etmek
2. **Dosya İçeriği Kontrolü**
    
    - Dosya içeriğini değiştirerek (örneğin, bir 
        
        .gif
        
         dosyasının içine PHP kodu ekleyerek) yüklemeyi denemek.
    - Yüklenen dosyanın içeriğinin sunucuda nasıl işlendiğini kontrol etmek.
3. **MIME Türü Kontrolü**
    
    - Dosyanın MIME türünü değiştirerek yüklemeyi denemek (örneğin, 
        
        .php
        
         dosyasının MIME türünü 
        
        image/jpeg
        
         olarak ayarlamak).
    - Sunucunun bu dosyayı kabul edip etmediğini kontrol etmek.
4. **Dosya Adı ve Yol Kontrolü**
    
    - Dosya adlarında ve yollarında tehlikeli karakterler kullanarak yüklemeyi denemek. (örneğin, 
        
        ../../
        
         gibi dizin geçiş karakterleri).
    - Sunucunun bu dosyaları kabul edip etmediğini ve doğru dizinde saklayıp saklamadığını kontrol etmek..
5. **Dosya Boyutu Kontrolü**
    
    - Çok büyük dosyalar yüklemeyi denemek.
    - Sunucunun dosya boyutu limitlerini nasıl kontrol ettiğini ve büyük dosyaları kabul edip etmediğini kontrol etmek.

Kaynak Kod Analizi

Unrestricted File Upload zafiyeti, dosya yükleme işlemi sırasında yeterli güvenlik kontrollerinin yapılmamasından kaynaklanır. Bu zafiyet, saldırganların zararlı dosyaları yükleyerek sunucuda komut çalıştırmasına veya hassas verilere erişmesine olanak tanır. Zafiyetin ortaya çıkış nedeni, dosya türü, boyutu, uzantısı ve içeriği gibi önemli doğrulamaların eksik olmasıdır.

Zafiyetli Kod Örneği

Aşağıdaki PHP kodu, bir dosya yükleme işlemini gerçekleştirmektedir. Ancak, bu kodda dosya türü, boyutu veya içeriği ile ilgili herhangi bir güvenlik kontrolü bulunmamaktadır.

```auto
<?php
    if( isset($_POST['submit']) ){

        $tmpName = $_FILES['input_image']['tmp_name'];
        $fileName = $_FILES['input_image']['name'];

        if(!empty($fileName)){
            if(!file_exists("uploads")){
                mkdir("uploads");
            }
    
            $uploadPath = "uploads/".$fileName;
    
            if( @move_uploaded_file($tmpName,$uploadPath) ){
                $status = "success";
                
            }else{
                $status = "unsuccess";
            }
        }else{
            $status = "empty";
        }
    }
?>
```

Bu kod, dosya türünü, MIME türünü veya dosya uzantısını doğrulamadan dosyayı yükler ve

uploads

dizinine kaydeder. Bu, zararlı dosyaların yüklenmesine ve sunucuda çalıştırılmasına olanak tanır.

Güvenli Kod Örneği

Aşağıda, dosya yükleme işlemi sırasında gerekli güvenlik kontrollerinin yapıldığı güvenli bir kod örneği bulunmaktadır:

```auto
<?php
    if( isset($_POST['submit']) ){

        $allowedTypes = ['image/jpeg', 'image/png', 'image/gif']; // PROTECTION
        $allowedExtensions = ['jpg', 'jpeg', 'png', 'gif']; // PROTECTION

        $fileType = mime_content_type($_FILES['input_image']['tmp_name']);
        $tmpName = $_FILES['input_image']['tmp_name'];
        $fileName = basename($_FILES['input_image']['name']);
        $fileExtension = strtolower(pathinfo($fileName, PATHINFO_EXTENSION));
      
        $uploadPath = "uploads/" . $fileName;

        // Check if file type and extension are allowed
        if (in_array($fileType, $allowedTypes) && in_array($fileExtension, $allowedExtensions)) {
            // Check if file already exists
            if (file_exists($uploadPath)) {
                $status = "file_exists";
            } else {
                // Create uploads directory if not exists
                if (!file_exists("uploads")) {
                    mkdir("uploads", 0755);
                }

                // Move uploaded file to the uploads directory
                if (@move_uploaded_file($tmpName, $uploadPath)) {
                    $status = "success";
                } else {
                    $status = "unsuccess";
                }
            }
        } else {
            $status = "invalid_type_or_extension";
        }
    }
?>
```

Bu güvenli kod örneğinde:

1. **Dosya Türü Kontrolü:** 
    
    mime_content_type
    
     fonksiyonu ile dosyanın MIME türü kontrol edilmekte ve sadece belirli türdeki dosyaların (JPEG, PNG, GIF) yüklenmesine izin verilmektedir.
2. **Dosya Uzantısı Kontrolü:** 
    
    pathinfo
    
     fonksiyonu ile dosyanın uzantısı kontrol edilmekte ve sadece belirli uzantıların (jpg, jpeg, png, gif) yüklenmesine izin verilmektedir.
3. **Dosya Adı Kontrolü:** 
    
    basename
    
     fonksiyonu ile dosya adı güvenli hale getirilmekte ve dizin geçiş saldırılarına karşı korunmaktadır.
4. **Dizin Kontrolü:** 
    
    uploads
    
     dizini yoksa oluşturulmakta ve dizin izinleri ayarlanmaktadır.
5. **Dosya Varoluş Kontrolü:** Aynı isimde bir dosya varsa uyarı verilmekte ve işlem iptal edilmektedir.
6. **Güvenli Dosya Taşıma:** 
    
    move_uploaded_file
    
     fonksiyonu ile dosya güvenli bir şekilde belirtilen dizine taşınmaktadır.

Bu kontroller, zararlı dosyaların yüklenmesini ve sunucuda çalıştırılmasını önlemeye yardımcı olur.
