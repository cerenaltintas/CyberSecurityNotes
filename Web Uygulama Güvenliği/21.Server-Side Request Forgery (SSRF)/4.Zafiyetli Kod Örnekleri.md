SSRF zafiyetinin temel nedeni, sunucu tarafında kaynak getirme (resource-fetching) işlevlerinde kullanıcıdan gelen girdinin yeterince doğrulanmadan veya filtrelenmeden kullanılmasıdır. Şimdi bu zafiyetin PHP ve Python dillerinde nasıl ortaya çıkabileceğini ve nasıl önlenebileceğini inceleyelim.

### PHP

PHP'de

file_get_contents()

,

curl_exec()

gibi fonksiyonlar, URL'lerden veri almak için yaygın olarak kullanılır. Eğer bu fonksiyonlara iletilen URL'ler kullanıcı kontrolündeyse ve doğrulanmazsa, SSRF zafiyetine yol açabilirler.

Zafiyetli PHP Kodu

Aşağıdaki örnekte,

url

GET parametresi ile alınan değer, herhangi bir kontrol olmaksızın doğrudan

file_get_contents()

fonksiyonuna verilir.

vulnerable.php

```auto
<?php
// Kullanıcıdan 'url' parametresini al
$url = $_GET['url'];

// Alınan URL'nin içeriğini getir ve ekrana yazdır.
// Bu fonksiyon http://, https://, file://, gopher:// gibi birçok farklı protokolü işleyebilir.
// Bu nedenle kullanıcı girdisiyle doğrudan kullanılması son derece tehlikelidir.
if (isset($url)) {
    $content = file_get_contents($url);
    echo $content;
} else {
    echo "Lütfen bir URL parametresi sağlayın.";
}
?>
```

**Zafiyetin Açıklaması:** Bu kodda, bir saldırgan

?url=http://127.0.0.1/server-status

gibi bir istek göndererek sunucunun iç durumu hakkında bilgi alabilir veya

?url=file:///etc/passwd

diyerek sunucudaki yerel dosyaları okuyabilir.

Güvenli PHP Kodu

SSRF'yi önlemenin en etkili yolu, yalnızca güvenilir ve beklenen hedeflere izin veren bir "allow-list" (izin listesi) uygulamaktır.

secure.php

```auto
<?php
// Yalnızca izin verilen alan adlarını içeren bir allow-list
$allowed_domains = ['api.external-site.com', 'static.another-site.org'];

$url = $_GET['url'];

if (isset($url)) {
    // URL'yi ayrıştırarak bileşenlerine ayır
    $parsed_url = parse_url($url);

    // Ana makine (host) adının alınıp alınamadığını kontrol et
    if (isset($parsed_url['host'])) {
        $host = $parsed_url['host'];

        // Ana makine adının izin listesinde olup olmadığını kontrol et
        if (in_array($host, $allowed_domains, true)) {
            // URL geçerliyse, isteği yap
            $content = file_get_contents($url);
            echo $content;
        } else {
            // Ana makine adı izin listesinde değilse, isteği engelle
            echo "Hata: İzin verilmeyen alan adı.";
        }
    } else {
        echo "Hata: Geçersiz URL formatı.";
    }
} else {
    echo "Lütfen bir URL parametresi sağlayın.";
}
?>
```

**Güvenlik Önleminin Açıklaması:**

1. **Allow-List:** Yalnızca belirli alan adlarına (
    
    api.external-site.com
    
    , 
    
    static.another-site.org
    
    ) istek yapılmasına izin verilir.
2. **URL Ayrıştırma:** 
    
    parse_url()
    
     fonksiyonu ile URL'nin 
    
    host
    
     kısmı alınır. Bu, 
    
    http://evil.com@good.com
    
     gibi karmaşık payload'ları atlatma girişimlerini zorlaştırır.
3. **Doğrulama:** Alınan 
    
    host
    
    , izin listesindeki değerlerle karşılaştırılır. Yalnızca eşleşme durumunda 
    
    file_get_contents()
    
     çağrılır.

### Python

Python'da

requests

veya

urllib

gibi kütüphaneler HTTP istekleri yapmak için kullanılır. Bu kütüphaneler de yanlış kullanıldığında SSRF'ye neden olabilir.

Zafiyetli Python Kodu (Flask Örneği)

Aşağıdaki Flask uygulaması,

url

parametresiyle gelen adrese istek gönderir ve içeriğini döndürür.

vulnerable_app.py

```auto
from flask import Flask, request
import requests

app = Flask(__name__)

@app.route("/fetch")
def fetch_url():
    # Kullanıcıdan 'url' parametresini al
    url = request.args.get('url')

    if url:
        try:
            # Alınan URL'ye doğrudan istek yap.
            # requests kütüphanesi localhost, iç IP adresleri ve file:// gibi şemaları takip edebilir.
            response = requests.get(url, timeout=5)
            return response.text
        except requests.exceptions.RequestException as e:
            return f"Hata: {str(e)}", 400
    return "Lütfen bir URL parametresi sağlayın."

if __name__ == "__main__":
    app.run(host='0.0.0.0', port=5000)
```

**Zafiyetin Açıklaması:** PHP örneğinde olduğu gibi, bu kod da bir saldırganın

?url=http://169.254.169.254/

gibi bir adresle bulut metadata servisine veya diğer iç servislere erişmesine olanak tanır.

Güvenli Python Kodu

Python'da da en güvenli yöntem bir "allow-list" kullanmaktır. Ek olarak, alan adının çözümlendiği IP adresinin özel bir ağa ait olup olmadığını kontrol etmek de güçlü bir savunma katmanı ekler.

secure_app.py

```auto
from flask import Flask, request
import requests
import socket
from urllib.parse import urlparse

app = Flask(__name__)

# Yalnızca izin verilen alan adları
ALLOWED_HOSTS = {'api.external-site.com', 'static.another-site.org'}

def is_internal_ip(ip):
    # IP adresinin özel (private) olup olmadığını kontrol et
    private_ip_ranges = [
        ("10.0.0.0", "10.255.255.255"),
        ("172.16.0.0", "172.31.255.255"),
        ("192.168.0.0", "192.168.255.255"),
        ("127.0.0.0", "127.255.255.255")
    ]
    ip_addr = socket.inet_aton(ip)
    for start, end in private_ip_ranges:
        if socket.inet_aton(start) <= ip_addr <= socket.inet_aton(end):
            return True
    return False

@app.route("/fetch")
def fetch_url():
    url = request.args.get('url')
    if not url:
        return "Lütfen bir URL parametresi sağlayın.", 400

    try:
        parsed_url = urlparse(url)
        hostname = parsed_url.hostname

        if not hostname:
            return "Geçersiz URL: Ana makine adı bulunamadı.", 400

        # 1. Ana makine adının izin listesinde olup olmadığını kontrol et
        if hostname not in ALLOWED_HOSTS:
            return f"Hata: İzin verilmeyen alan adı: {hostname}", 403

        # 2. Alan adını IP adresine çözümle
        ip_address = socket.gethostbyname(hostname)

        # 3. IP adresinin iç ağa ait olup olmadığını kontrol et
        if is_internal_ip(ip_address):
            return f"Hata: İç ağ adreslerine istek yapılamaz: {ip_address}", 403

        # Tüm kontrollerden geçtiyse isteği yap
        response = requests.get(url, timeout=5)
        return response.text

    except (requests.exceptions.RequestException, socket.gaierror) as e:
        return f"Hata: {str(e)}", 400

if __name__ == "__main__":
    app.run(host='0.0.0.0', port=5000)
```

**Güvenlik Önleminin Açıklaması:**

1. **Allow-List Kontrolü:** 
    
    urlparse
    
     ile URL'den ayrıştırılan 
    
    hostname
    
    , 
    
    ALLOWED_HOSTS
    
     listesinde kontrol edilir.
2. **IP Adresi Çözümlemesi:** 
    
    socket.gethostbyname()
    
     ile alan adı bir IP adresine çözümlenir.
3. **İç IP Kontrolü:** Çözümlenen IP adresinin özel (iç ağ) bir IP olup olmadığı 
    
    is_internal_ip
    
     fonksiyonu ile kontrol edilir. Bu, DNS rebinding gibi daha karmaşık saldırılara karşı ek bir koruma katmanı sağlar.

**DNS Rebinding**: Bir alan adının IP adresini zamanla değiştirerek SSRF filtrelerini atlatmayı amaçlayan bir tekniktir. Güvenlik mekanizması bir alan adını ilk kontrol ettiğinde güvenli bir genel IP adresi görür, ancak asıl istek yapılana kadar geçen sürede (DNS TTL süresi dolduğunda) aynı alan adı artık

127.0.0.1

gibi bir iç ağ adresine çözümlenir. Bu, IP tabanlı kara liste kontrollerini etkisiz hale getirir.
