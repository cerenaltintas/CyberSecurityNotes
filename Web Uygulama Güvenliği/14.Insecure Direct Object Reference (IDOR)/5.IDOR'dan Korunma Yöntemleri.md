IDOR zafiyetlerinden korunmak için uygulamanın her aşamasında yetkilendirme ve doğrulama kontrollerini etkin bir şekilde uygulamak önemlidir.

### 1. Yetkilendirme Kontrolleri

**Yetkilendirme Nedir?**

Yetkilendirme, kimlik doğrulaması yapılmış bir kullanıcının sistemde hangi verilere ve kaynaklara erişimi olduğunu belirler. Her nesneye erişim izni verilmeden önce kullanıcının bu nesneye erişim hakkına sahip olduğundan emin olunmalıdır.

**Örnek: Basit Yetkilendirme**

Kullanıcının yalnızca kendi sipariş bilgilerine erişebilmesi gerektiğini varsayalım. Python'da Flask framework'ü ile basit bir kontrol aşağıdaki gibidir.

```auto
from flask import Flask, request, jsonify

app = Flask(__name__)

# Sample order data stored in the database
orders = {
    1: {"user_id": 1, "details": "Order 1 details"},
    2: {"user_id": 2, "details": "Order 2 details"}
}

# Authenticated user information
logged_in_user = {"id": 1, "username": "user1"}

@app.route('/order/<int:order_id>', methods=['GET'])
def get_order(order_id):
    order = orders.get(order_id)
    
    if order and order['user_id'] == logged_in_user['id']:
        return jsonify(order), 200
    else:
        return jsonify({"error": "Unauthorized access"}), 403

if __name__ == '__main__':
    app.run(debug=True)
```

Bu örnekte,

order_id

ile erişilen her siparişin, kimlik doğrulaması yapılmış kullanıcının

user_id

'si ile eşleşip eşleşmediği kontrol ediliyor.

### 2. Dolaylı Nesne Referansları Kullanımı

Doğrudan artan nesne kimlikleri yerine şifrelenmiş veya karmaşık referanslar kullanmak, saldırganların tahmin etmesini zorlaştırır.

**Örnek: UUID Kullanımı**

UUID (Universally Unique Identifier) gibi benzersiz referanslar, nesne kimliklerinin tahmin edilmesini zorlaştırır.

```auto
import uuid

# UUID generation
user_uuid = str(uuid.uuid4())
print(f"User UUID: {user_uuid}")

# Storing user data with UUID
users = {
    user_uuid: {"username": "user1", "email": "user1@example.com"}
}

# Access control
@app.route('/user/<uuid:user_id>', methods=['GET'])
def get_user(user_id):
    user = users.get(str(user_id))
    
    if user:
        return jsonify(user), 200
    else:
        return jsonify({"error": "User not found"}), 404
```

UUID kullanarak **benzersiz** ve **tahmin edilemez** bir nesne referansı oluşturulmuş olur.

### 3. Veri Azaltma

API veya uygulama uç noktaları, sadece gerekli verileri sağlamalıdır. Gereğinden fazla veri döndürmek, saldırganların sistemdeki yapıyı daha kolay anlamasına neden olur.

**Örnek: JSON Yanıtını Sınırlama**

Bir kullanıcının kimlik bilgilerini yalnızca gerekli alanlarla döndürmek için örnek.

```auto
@app.route('/user/info', methods=['GET'])
def get_user_info():
    # Sample user data
    user_info = {
        "username": "user1",
        "email": "user1@example.com",
        "phone": "1234567890",
        "address": "123 Main St."
    }

    # Return only the necessary information
    response_data = {
        "username": user_info["username"],
        "email": user_info["email"]
    }

    return jsonify(response_data), 200
```

Bu örnekte, kullanıcı kimlik bilgileri yalnızca sınırlı alanlarla döndürülür.

### 4. Günlük Kayıtları ve İzleme

Şüpheli aktiviteleri erkenden tespit etmek için günlük kayıtları tutulmalı ve izleme yapılmalıdır. Örneğin, aynı istemciden kısa sürede gelen çok sayıda istek, bir **mass enumeration** saldırısını gösterebilir.

Manuel ve otomatik güvenlik testleri, uygulamanızın zafiyetlerini ortaya çıkarır.

- **Otomatik Tarama:** Güvenlik tarama araçları ile API uç noktalarını ve web uygulamalarını tarayın.
