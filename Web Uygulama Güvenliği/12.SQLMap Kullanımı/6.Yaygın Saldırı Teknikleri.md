Bu kısımda, SQLMap'in

--technique

parametresi kullanılarak gerçekleştirilebilecek yaygın saldırı teknikleri ve bu tekniklerin nasıl uygulanacağına değinelim.

### Error Based SQL Injection (E)

Error Based SQL Injection, uygulamanın SQL sorgularından kaynaklanan hata mesajlarını kullanarak veritabanı yapısını çıkarmayı amaçlar. SQLMap bu tür açıkları otomatik olarak tespit edip, veritabanından veri çekebilir.

**Örnek Kullanım**

```auto
sqlmap -u "http://example.com/vulnerable.php?id=1" --technique=E
```

### Blind SQL Injection (B)

Blind SQL Injection, veritabanı sorgularının doğru veya yanlış sonuçlarını yorumlayarak veri çıkarmaya çalışır. True/False cevaplarına dayanan bu yöntem, hata mesajı olmadan veritabanı içeriğini çıkarmak için kullanılır.

**Örnek Kullanım**

```auto
sqlmap -u "http://example.com/vulnerable.php?id=1" --technique=B
```

### Union Query SQL Injection (U)

Union Query SQL Injection,

UNION SELECT

sorguları kullanarak birden fazla sorgunun sonuçlarını birleştirip, bu bilgileri çıkarmayı amaçlar. Bu teknik, aynı zamanda veritabanı sorgularını manipüle ederek ekstra bilgiler elde etmek için de kullanılabilir.

**Örnek Kullanım**

```auto
sqlmap -u "http://example.com/vulnerable.php?id=1" --technique=u
```

### Stacked Queries SQL Injection (S)

Stacked Queries SQL Injection, tek bir sorgu içinde birden fazla SQL ifadesi çalıştırmayı sağlar. Bu sayede saldırgan, veritabanında ek komutlar yürüterek daha fazla kontrol sahibi olabilir.

**Örnek Kullanım**

```auto
sqlmap -u "http://example.com/vulnerable.php?id=1" --technique=S
```

### Time-based Blind SQL Injection (T)

Time-based Blind SQL Injection, veritabanı sorgusunun yanıt süresini takip ederek bilgi sızdırmayı amaçlar. Sorgu doğru olduğunda, yanıtta gecikme oluşturarak saldırganın sorgu doğruluğunu anlamasını sağlar.

**Örnek Kullanım**

```auto
sqlmap -u "http://example.com/vulnerable.php?id=1" --technique=T
```

### Out-of-band SQL Injection (Q)

Out-of-band SQL Injection, veritabanı sunucusunun saldırgan kontrolündeki bir sunucu ile etkileşime geçmesine neden olarak bilgi sızdırır.

**Örnek Kullanım**

```auto
sqlmap -u "http://example.com/vulnerable.php?id=1" --technique=Q
```
