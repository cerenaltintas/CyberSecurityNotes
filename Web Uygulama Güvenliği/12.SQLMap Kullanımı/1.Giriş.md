SQLMap, siber güvenlik uzmanlarının uygulamalarda SQL enjeksiyon açıklarını tespit etmelerine ve sömürmelerine olanak tanıyan açık kaynaklı bir araçtır. SQL enjeksiyonu, bir saldırganın zararlı SQL kodunu bir uygulamanın veritabanına göndererek verilere erişmesine veya bu verileri değiştirmesine izin veren bir güvenlik açığıdır. Bu tür açıklar, web uygulamalarında yaygın olarak bulunabilir ve ciddi güvenlik ihlallerine yol açabilir. SQLMap, bu tür zafiyetlerin otomatik olarak keşfedilmesi ve sömürülmesi için tasarlanmış bir araçtır. SQLMap sayesinde geliştiriciler ve siber güvenlik uzmanları uygulamalardaki güvenlik açıklarını daha etkili bir şekilde tespit edebilirler.

SQLMap, kullanıcıya çok çeşitli veritabanı yönetim sistemlerini test etme yeteneği sunar. Desteklediği veritabanları arasında MySQL, Oracle, PostgreSQL, Microsoft SQL Server, SQLite ve daha pek çok veri tabanı bulunmaktadır.

Bağlantı: [https://github.com/sqlmapproject/sqlmap](https://github.com/sqlmapproject/sqlmap)

### SQLMap Özellikleri

SQLMap, web uygulamalarındaki SQL enjeksiyon açıklarını keşfetmek ve sömürmek için güçlü özellikler sunar.

- **Çoklu Veritabanı Desteği:** MySQL, Oracle, PostgreSQL, Microsoft SQL Server, SQLite, ve daha fazlası.
- **Veritabanı Otomatik Tespiti:** Kullanılan veritabanı sistemini otomatik olarak belirler.
- **Veri Çıkarma:** Veritabanından tablolar, sütunlar ve verilerin çekilmesi.
- **SQL Enjeksiyon Teknikleri:** Boolean-based blind, Time-based blind, Error-based, UNION query, Stacked queries
- **Detaylı Veritabanı Bilgisi:** Veritabanı yapısını, kullanıcı haklarını ve sistem verilerini alır.
- **Komut Yürütme:** Veritabanı üzerinde SQL komutları çalıştırma.
- **Otomasyon:** Komut dosyaları ve API aracılığıyla taramaları otomatize etme.
- **Kullanıcı Dostu Arayüz:** Kolay kullanım için komut satırı arayüzü.
- **Sızma Testi Araçlarıyla Entegrasyon:** Metasploit gibi diğer güvenlik araçlarıyla entegrasyon.
- **Proxy Desteği:** HTTP ve SOCKS proxy üzerinden bağlantı yapabilme.

### SQLMap Entegrasyonları

SQLMap, çeşitli araçlar ve platformlarla entegre edilebilir, böylece güvenlik testleri gerçekleştirirken daha geniş bir kapsam sağlar.

- **Metasploit:** Güvenlik açıklarını otomatik olarak sömürebilir ve test senaryolarını genişletebilir.
- **Burp Suite:** Proxy trafik verilerini SQLMap'e vererek dinamik analiz sağlar.
- **OWASP ZAP:** ZAP aracılığıyla toplanan verileri SQLMap ile işleyerek detaylı güvenlik testleri yapılmasına olanak tanır.
- **WebScarab:** Çapraz platform desteği ile SQL enjeksiyonu testleri için veri sağlar.
- **Maltego:** Ağ haritalaması ve veri toplama işlemleri için SQLMap ile entegrasyon sağlar.
- **Wireshark:** Ağ trafiğini analiz ederek SQLMap'in işleyebileceği verileri elde eder.
- **Cuckoo Sandbox:** Zararlı yazılım analizi sırasında elde edilen veritabanı bilgilerini SQLMap ile işleme.
- **W3af:** Web uygulama güvenlik tarayıcısı ile SQLMap'i birleştirerek kapsamlı güvenlik denetimleri yapılabilir.

### Kurulum ve Kulllanım

**Bağımlılıklar** SQLMap, Python programlama dilinde geliştirilen, dinamik ve nesne yönelimli bir araçtır. Python, çeşitli işletim sistemlerinde kullanılabilen, ücretsiz olarak indirilebilen bir programlama dilidir. SQLMap, Python'un

2.6

,

2.7

veya

3.x

gibi sürümlerini destekler.

SQLMap'in bazı gelişmiş özellikleri,

Metasploit Framework

gibi ek araçlara bağlıdır. Bu özellikler, Metasploit Framework'ün

3.5

veya daha yeni bir sürümünü gerektirir. Ayrıca, ICMP tünellemesi gibi teknikler için

Impacket

kütüphanesi gereklidir.

Eğer bir web uygulaması aracılığıyla değil, doğrudan bir veritabanı sunucusuna bağlanmayı düşünüyorsanız (SQLMap'te -d seçeneği ile), hedeflediğiniz veritabanı yönetim sistemi için gerekli Python bağlantılarını kurmanız gerekir. İşte bazı yaygın veritabanı sistemleri ve ilgili Python paketleri:

- DB2 için: python ibm-db
- Firebird için: python-kinterbasdb
- Microsoft Access için: python-pyodbc
- Microsoft SQL Server için: python-pymssql
- MySQL için: python pymysql
- Oracle için: python cx_Oracle
- PostgreSQL için: python-psycopg2
- SQLite için: python-pysqlite2
- Sybase için: python-pymssql

Eğer hedef web uygulaması NTLM kimlik doğrulaması kullanıyorsa,

python-ntlm

kütüphanesini kurmanız gerekmektedir.

Windows üzerinde SQLMap kullanıyorsanız, SQL kabuğu ve işletim sistemi kabuğunda sekme tamamlama ve geçmiş özelliklerini kullanmak için

PyReadline

kütüphanesini kurabilirsiniz. Bu işlevler, diğer işletim sistemlerinde Python'un standart readline kütüphanesi ile doğal olarak kullanılabilir.
