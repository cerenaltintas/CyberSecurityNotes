WordPress kullanıcılarını tespit etmek, bir saldırganın siteye giriş yapmayı denemesi veya sosyal mühendislik saldırıları planlaması için önemlidir. Kullanıcıların kimlik bilgilerini elde etmek, siteye yetkisiz erişim sağlamak için kullanılabilecek önemli bir adımdır. Bu bölümde, WordPress kullanıcılarını tespit etmenin çeşitli yöntemlerini ele alacağız.

### 1. User ID Brute Force

WordPress, kullanıcıların kimliklerini ve profillerini tespit etmek için belirli bir mantığa göre kullanıcı kimlik numaralarını (user IDs) kullanır. Kullanıcı kimlik numaraları, sıralı ve tahmin edilebilir olduğundan, bir kullanıcı kimliği tahmin edilerek ilgili kullanıcı adına ulaşılabilir.

1.1 Author Archives

WordPress, yazarların gönderilerini listelerken yazar arşivlerini kullanır. Bu arşivler genellikle aşağıdaki gibi yapılandırılmış URL'lere sahiptir.

```auto
https://<target-website>/?author=1
https://<target-website>/?author=2
```

Bu URL'lere gidildiğinde, yazarın kullanıcı adı genellikle URL'de veya sayfa içeriğinde görünür. Örneğin:

```auto
https://<target-website>/author/username/
```

Bu,

author=1

ve

author=2

gibi art arda gelen sayıları deneyerek farklı kullanıcıların adlarını tespit etmeyi sağlar.

1.2 XML-RPC API

WordPress,

dosyasına yapılacak bir POST isteği ile bu bilgi doğrulanabilir. Örneğin, bir

Eğer kullanıcı adı doğruysa, WordPress geçerli bir yanıt döndürecektir. Yanıtı alarak, kullanıcının varlığını doğrulayabilirsiniz.

### 2. wp-json API

WordPress'in REST API'si, kullanıcı adlarını tespit etmek için kullanılabilir. REST API, kullanıcı bilgilerini JSON formatında sunar. Kullanıcıları tespit etmek için şu URL'yi ziyaret edebilirsiniz:

```auto
https://<target-website>/wp-json/wp/v2/users
```

Bu URL, siteye kayıtlı kullanıcıların listesini döndürebilir. Elde edilen JSON verisi, kullanıcı adlarını ve kimlik numaralarını içerebilir.

### 3. Login Username Enumeration

WordPress giriş sayfası, kullanıcı adlarını tespit etmek için kullanılabilir. Giriş sayfasında doğru veya yanlış kullanıcı adı girişi yapıldığında verilen hata mesajları, kullanıcı adının doğru olup olmadığını belirlemenize yardımcı olabilir.

3.1 wp-login.php

WordPress'in varsayılan giriş sayfası

wp-login.php

dosyasıdır. Bu sayfada yanlış kullanıcı adı veya parola girildiğinde verilen hata mesajları incelenebilir. Örneğin:

- **Yanlış kullanıcı adı girildiğinde.**

```auto
ERROR: Invalid username.
```

- **Doğru kullanıcı adı ve yanlış parola girildiğinde.**

```auto
ERROR: The password you entered for the username 'username' is incorrect.
```

Bu hata mesajları, kullanıcı adlarının doğru olup olmadığını anlamak için kullanılabilir.

3.2 Brute Force Araçları

Kullanıcı adı enumeration işlemi için otomatik araçlar kullanılabilir. WPScan gibi araçlar, kullanıcı adlarını tespit etmek için brute force saldırıları gerçekleştirebilir. WPScan kullanarak kullanıcı adlarını tespit etmek için aşağıdaki komut kullanılabilir.

```auto
wpscan --url https://<target-website> --enumerate u
```

Bu komut, belirtilen URL'deki kullanıcı adlarını tespit etmeye çalışacaktır.
