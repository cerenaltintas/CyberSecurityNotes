WordPress sürüm bilgisini tespit etmek, bir web sitesinin güvenlik durumunu anlamak için önemli bir ilk adımdır. Kullanılan WordPress sürümü, belirli güvenlik açıklarına sahip olabilir ve bu bilgiyi bilmek önemli bir avantaj sağlayabilir. Bu bölümde, WordPress çekirdek sürümünü belirlemenin çeşitli yöntemlerini ele alacağız.

### 1. Meta Generator Etiketi

WordPress, varsayılan olarak sayfanın HTML kaynak koduna bir meta generator etiketi ekler. Bu etiket, kullanılan WordPress sürümünü açıkça belirtir. Meta generator etiketini bulmak için, sayfanın kaynak kodunu görüntüleyebilir ve aşağıdaki örnekte olduğu gibi bir satır arayabilirsiniz.

```auto
<meta name="generator" content="WordPress 5.7" />
```

Bu etiket, tarayıcınızın "Kaynağı Görüntüle" özelliği kullanılarak kolayca bulunabilir.

### 2. readme.html Dosyası

WordPress kurulumunun kök dizininde genellikle

readme.html

adlı bir dosya bulunur. Bu dosya, yüklü olan WordPress sürümü hakkında bilgi içerir. Bu dosyayı bulmak için tarayıcınızda şu URL'yi ziyaret edebilirsiniz.

```auto
https://<target-website>/readme.html
```

Bu dosyada, genellikle sürüm bilgisi ve diğer yararlı bilgiler bulunur.

### 3. CSS ve JavaScript Dosyaları

Bazı WordPress temaları ve eklentileri, sürüm bilgilerini CSS veya JavaScript dosyalarında saklayabilir. Bu bilgiler, HTML kaynağında ilgili dosya bağlantılarında belirtilebilir. Örneğin:

```auto
<link rel='stylesheet' href='https://<target-website>/wp-content/themes/twentytwenty/style.css?ver=5.7' />
```

Bu örnekte,

ver=5.7

parametresi, kullanılan WordPress sürümünü belirtir. Bu tür bilgileri bulmak için HTML kaynağındaki link ve script etiketlerini inceleyebilirsiniz.

### 4. wp-includes/version.php Dosyası

WordPress sürüm bilgisi, wp-includes/version.php dosyasında da bulunabilir. Bu dosyaya erişim sağlayarak sürüm bilgisini öğrenebilirsiniz. Örneğin:

```auto
$wp_version = '5.7';
```

### 5. Çeşitli Araçlar ve Komutlar

Birçok güvenlik aracı, WordPress sürüm bilgisini tespit etmek için kullanılabilir. Bu araçlar arasında WPScan gibi güvenlik tarama araçları bulunmaktadır. WPScan kullanarak sürüm bilgisini tespit etmek için şu komutu kullanabilirsiniz:

```auto
wpscan --url https://<target-website> --enumerate v
```

Bu komut, belirtilen URL'deki WordPress sürümünü tespit etmeye çalışacaktır.
