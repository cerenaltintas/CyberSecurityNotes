WordPress, çok çeşitli işletim sistemleri üzerinde çalışabilen esnek ve güçlü bir içerik yönetim sistemidir. Bu bölümde, özellikle Ubuntu Linux web sunucusunda varsayılan olarak kurulan bir WordPress'in yapısını ele alacağız.

### WordPress Kurulumu

WordPress kurulumu için, yapılandırılmış bir LAMP yığını gerektirir. LAMP, aşağıdaki bileşenlerden oluşur.

- Linux İşletim Sistemi
- Apache HTTP Sunucusu
- MySQL Veritabanı
- PHP Programlama Dili

Bu bileşenler kurulduktan sonra, WordPress dosyaları ve dizinleri indirilir. WordPress dosyaları genellikle webroot olarak adlandırılan

/var/www/html

dizinine konumlandırılır.

### WordPress Dizin Yapısı

Varsayılan bir WordPress kurulumunun dizin yapısı aşağıdaki gibidir.

```auto
tree -L 1 /var/www/html

├── index.php
├── license.txt
├── readme.html
├── wp-activate.php
├── wp-admin
├── wp-blog-header.php
├── wp-comments-post.php
├── wp-config.php
├── wp-config-sample.php
├── wp-content
├── wp-cron.php
├── wp-includes
├── wp-links-opml.php
├── wp-load.php
├── wp-login.php
├── wp-mail.php
├── wp-settings.php
├── wp-signup.php
├── wp-trackback.php
└── xmlrpc.php
```

### Önemli WordPress Dosyaları

WordPress'in kök dizininde, sitenin doğru şekilde çalışması için gerekli olan önemli dosyalar bulunur.

- **index.php:** WordPress'in ana sayfasıdır.
- **license.txt:** Yüklü WordPress sürümü hakkında bilgi içerir.
- **wp-activate.php:** Yeni bir WordPress sitesi kurarken e-posta aktivasyonu için kullanılır.
- **wp-config.php:** WordPress'in veritabanına bağlanması için gerekli bilgileri içerir. Bu dosyada veritabanı adı, kullanıcı adı, şifre, kimlik doğrulama anahtarları ve tuzlama kelimeleri gibi bilgiler bulunur.

wp-config.php

Bu dosya, WordPress'in veritabanı ile bağlantı kurması için gerekli bilgileri içerir.

```auto
<?php
/** Veritabanı adı */
define( 'DB_NAME', 'database_name_here' );

/** MySQL veritabanı kullanıcı adı */
define( 'DB_USER', 'username_here' );

/** MySQL veritabanı şifresi */
define( 'DB_PASSWORD', 'password_here' );

/** MySQL sunucu adı */
define( 'DB_HOST', 'localhost' );

/** Kimlik doğrulama anahtarları ve tuzlar */
define( 'AUTH_KEY',         'benzersiz kelimenizi buraya koyun' );
define( 'SECURE_AUTH_KEY',  'benzersiz kelimenizi buraya koyun' );
define( 'LOGGED_IN_KEY',    'benzersiz kelimenizi buraya koyun' );
define( 'NONCE_KEY',        'benzersiz kelimenizi buraya koyun' );
define( 'AUTH_SALT',        'benzersiz kelimenizi buraya koyun' );
define( 'SECURE_AUTH_SALT', 'benzersiz kelimenizi buraya koyun' );
define( 'LOGGED_IN_SALT',   'benzersiz kelimenizi buraya koyun' );
define( 'NONCE_SALT',       'benzersiz kelimenizi buraya koyun' );

/** WordPress Veritabanı Tablo Ön Ekini Belirtir */
$table_prefix = 'wp_';

/** Geliştiriciler için WordPress hata ayıklama modu */
define( 'WP_DEBUG', false );

/** WordPress dizinine mutlak yol */
if ( ! defined( 'ABSPATH' ) ) {
    define( 'ABSPATH', __DIR__ . '/' );
}

/** WordPress değişkenlerini ve dahil edilen dosyaları ayarlar */
require_once ABSPATH . 'wp-settings.php';
```

### Önemli WordPress Dizinleri

- **wp-content:** Eklentiler ve temaların depolandığı ana dizindir. Bu dizin, genellikle platforma yüklenen dosyaların bulunduğu uploads alt dizinini de içerir.

```auto
tree -L 1 /var/www/html/wp-content

├── index.php
├── plugins
└── themes
```

- **wp-includes:** Yönetim bileşenleri ve temalar dışında kalan tüm temel dosyaları içerir. Bu dizin, sertifikalar, yazı tipleri, JavaScript dosyaları ve widget'lar gibi çekirdek dosyaları barındırır.

```auto
tree -L 1 /var/www/html/wp-includes

├── theme.php
├── update.php
├── user.php
├── vars.php
├── version.php
├── widgets
├── widgets.php
├── wlwmanifest.xml
├── wp-db.php
└── wp-diff.php
```

### WordPress Kullanıcı Rolleri

Standart bir WordPress kurulumunda beş tür kullanıcı rolü bulunur.

|Rol|Açıklama|
|---|---|
|Administrator|Kullanıcı ekleme/silme, yazı ekleme/silme, kaynak kodu düzenleme gibi yönetici özelliklerine erişebilir.|
|Editor|Kendi yazıları ve diğer kullanıcıların yazılarını yayınlayabilir ve yönetebilir.|
|Author|Kendi yazılarını yayınlayabilir ve yönetebilir.|
|Contributor|Kendi yazılarını yazabilir ve yönetebilir, ancak yayınlayamaz.|
|Subscriber|Yazıları görüntüleyebilir ve profillerini düzenleyebilir.|
