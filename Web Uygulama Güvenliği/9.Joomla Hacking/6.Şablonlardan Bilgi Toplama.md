Template Enumeration, bir saldırganın veya güvenlik test uzmanının Joomla sitelerinde kullanılan şablonları tespit etmeye yönelik gerçekleştirdiği işlemleri kapsar. Şablonlar, bir sitenin görünümünü ve düzenini belirleyen önemli bileşenlerdir. Kullanılan şablonlar ve sürümleri hakkında bilgi sahibi olmak, potansiyel güvenlik açıklarını belirlemek ve uygun güvenlik önlemlerini almak için kritik öneme sahiptir. Bu bölümde, Joomla şablonlarının nasıl tespit edilebileceğini ve pratikte uygulanabilir örnekleri detaylı bir şekilde ele alacağız.

### Manuel Yöntemler

1. HTML Kaynağı İnceleme

Web sayfasının HTML kaynak kodunu inceleyerek kullanılan şablonları tespit edebilirsiniz. Şablonlara özgü CSS veya JavaScript dosyaları ipuçları sağlar.

```auto
<link rel="stylesheet" href="/templates/protostar/css/template.css" type="text/css">
<script src="/templates/protostar/js/template.js" type="text/javascript"></script>
```

Yukarıdaki örnekte, protostar şablonunun kullanıldığı görülmektedir.

2. URL Yapısı ve Parametreler

Joomla URL yapısı ve parametreleri, hangi şablonların kullanıldığını gösterebilir.

**Örnek:**

```auto
http://example.com/index.php?template=protostar
```

template=protostar parametresi, protostar şablonunun kullanıldığını belirtir.

3. HTTP Başlıkları ve Yanıtları

HTTP başlıklarını ve yanıtlarını inceleyerek şablon bilgilerini bulabilirsiniz.

**Örnek:**

```auto
GET /templates/protostar/css/template.css HTTP/1.1
Host: example.com
```

Bu istek, protostar şablonunun kullanıldığını gösterir.
