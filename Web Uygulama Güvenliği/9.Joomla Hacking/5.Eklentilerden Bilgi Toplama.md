Joomla sitelerinde kullanılan eklentilerin (bileşenler, modüller ve eklentiler) tespit edilmesi, sitenin güvenliğini değerlendirmek ve potansiyel zafiyetleri belirlemek için önemli bir taramadır. Eklenti enumeration işlemi, kullanılan üçüncü taraf yazılımların sürümlerini ve yapılarını tespit etmeyi içerir.

### Eklenti Enumeration Yöntemleri

Manuel Yöntemler

Web tarayıcıları ve HTTP isteği inceleme araçları kullanarak manuel olarak bilgi toplama.

Otomatik Araçlar

Eklenti enumeration sürecini otomatikleştiren araçlar kullanmak, daha hızlı ve kapsamlı sonuçlar elde etmenizi sağlar.

### Manuel Yöntemler

1. HTML Kaynağı İnceleme

Web sayfasının HTML kaynak kodunu inceleyerek kullanılan eklentileri tespit edebilirsiniz. Bileşenlere, modüllere veya eklentilere özgü CSS veya JavaScript dosyaları ipuçları sağlar.

**Örnek:**

```auto
<link rel="stylesheet" href="/media/com_contact/css/style.css" type="text/css">
<script src="/media/com_content/js/script.js" type="text/javascript"></script>
```

Yukarıdaki örnekte, com_contact bileşeni ve com_content bileşenine ait dosyalar bulunabilir.

2. URL Yapısı ve Parametreler

Joomla URL yapısı ve parametreleri, hangi bileşenlerin kullanıldığını gösterebilir.

**Örnek:**

```auto
http://example.com/index.php?option=com_content&view=article&id=1
```

3. HTTP Başlıkları ve Yanıtları

HTTP başlıklarını ve yanıtlarını inceleyerek eklenti bilgilerini bulabilirsiniz.

```auto
GET /components/com_contact/ HTTP/1.1
Host: example.com
```

### Otomatik Araçlar

1. JoomScan

JoomScan, Joomla sitelerindeki eklentileri ve güvenlik açıklarını taramak için kullanılan popüler bir araçtır.

```auto
./joomscan.pl -u http://example.com
```

2. CMSMap

CMSMap, çeşitli içerik yönetim sistemlerini tarayan ve zafiyetleri tespit eden bir araçtır.

```auto
python cmsmap.py -t http://example.com -f
```

3. JoomlaVS

JoomlaVS, Joomla sitelerinde kullanılan eklentileri ve sürümlerini tespit eden bir başka araçtır.

```auto
python joomlavs.py -u http://example.com
```
