Joomla Core Enumeration ile Joomla sitelerindeki çekirdek bileşenlerin sürümlerini ve yapılarını tespit etmeye yönelik gerçekleştirilebilecek işlemleri inceleyeceğiz. Bu bilgi(ler), potansiyel güvenlik açıklarını belirlemek ve uygun güvenlik önlemlerini almak için kritik öneme sahiptir.

### Joomla Sürüm Tespiti

Joomla'nın sürümünü tespit etmek, güvenlik açıklarını bulmak için önemli bir adımdır. Joomla'nın sürüm bilgileri çeşitli kaynaklardan elde edilebilir.

1. 

joomla.xml

 Dosyası

Joomla sürüm bilgisi ve uzantı dosyaları, Joomla'nın hangi sürümünün kullanıldığını ve yüklü uzantıların (komponentler, modüller, eklentiler) detaylarını içeren XML dosyalarıdır. Bu bilgiler, Joomla'nın güvenlik durumunu değerlendirmek, güncellemelerin yönetilmesi ve sistemin genel yapılandırmasını anlamak için kritik öneme sahiptir.

Tipik bir Joomla sürüm bilgisi XML dosyası (

administrator/manifests/files/joomla.xml

) şöyle bir yapıya sahip olabilir:

```auto
<extension type="file" version="3.9.20" method="upgrade">
    <name>Joomla</name>
    <author>Joomla! Project</author>
    <creationDate>July 2020</creationDate>
    <copyright>Open Source Matters</author>
    <license>GNU General Public License version 2 or later; see LICENSE.txt</license>
    <authorEmail>admin@joomla.org</authorEmail>
    <authorUrl>www.joomla.org</authorUrl>
    <version>3.9.20</version>
</extension>
```

Bu XML dosyası Joomla sürümünü, oluşturulma tarihini, lisans bilgisini ve yazar bilgilerini içerir. Benzer şekilde, diğer yüklü uzantıların bilgileri de ilgili XML dosyalarında bulunabilir.

- **Joomla Sürüm Bilgisi Dosyası Yolu:** Joomla kurulumunda, sürüm bilgisi dosyası 
    
    administrator/manifests/files/joomla.xml
    
     adresinde yer alır. Bu dosya, Joomla'nın hangi sürümünün kurulu olduğunu ve temel yazar bilgilerini içerir.
- **Diğer Uzantıların XML Dosyaları:** Uzantılara özgü XML dosyaları, genellikle aynı 
    
    administrator/manifests/files/
    
     dizini altında bulunur. Bu dosyalar, her bir uzantının sürümü, yazarı, lisans bilgisi gibi detayları içerir.

Bu dosyalar, Joomla sisteminin güvenlik incelemelerinde ve yönetiminde önemli rol oynar, özellikle sistemin güncellenmesi veya güvenlik açıklarının tespit edilmesi gibi durumlarda referans noktası olarak kullanılır.

2. Joomla API Kullanımı: Kullanıcı Bilgilerine Erişim

Joomla API'si, Joomla platformunda programatik olarak veri almak ve göndermek için kullanılır. Özellikle, RESTful API aracılığıyla çeşitli işlemler gerçekleştirilebilir. Örneğin,

/api/index.php/v1/users?public=true

API endpoint'ini kullanarak, kamuoyuna açık kullanıcı bilgilerini alabilirsiniz. Bu tür bir sorgu, genellikle sistemdeki kullanıcıların listesini döndürür, ancak

public=true

parametresi sayesinde yalnızca kamuoyuna açık olarak işaretlenmiş kullanıcı bilgilerini getirir.

API sorgusunun tipik bir çıktısı JSON formatında olabilir ve kullanıcıların isimleri, kullanıcı adları ve diğer kamuoyuna açık bilgileri içerebilir. İşte bir örnek:

```auto
{
  "links": {
    "self": "http://example.com/api/index.php/v1/users?public=true"
  },
  "data": [
    {
      "type": "users",
      "id": "123",
      "attributes": {
        "id": 123,
        "name": "Example User",
        "username": "exampleuser",
        "email": "exampleuser@example.com",
        "block": 0,
        "sendEmail": 1,
        "registerDate": "2024-01-01 12:00:00",
        "lastvisitDate": "2024-01-01 12:15:00",
        "lastResetTime": null,
        "resetCount": 0,
        "group_count": 1,
        "group_names": "Registered"
      }
    }
  ],
  "meta": {
    "total-pages": 1
  }
}
```

Bu çıktı, API aracılığıyla elde edilen kullanıcıların listesini gösterir. Her kullanıcı nesnesi, kullanıcının ID'si, tam adı, kullanıcı adı ve e-posta adresini içerir.

- **API Endpoint Yolu:** Joomla API yolu 
    
    /api/index.php/v1/users?public=true
    
     şeklinde tanımlanmıştır. Bu yol, Joomla'nın API sistemine yapılan HTTP GET isteği ile kullanıcı bilgilerine erişim sağlar.

Bu API endpoint'ini kullanmak için Joomla'nın API özelliklerinin etkinleştirilmiş ve düzgün bir şekilde yapılandırılmış olması gerekmektedir. Eğer sisteminizde Joomla'nın en son sürümü kullanılmıyorsa veya belirli güvenlik ayarları yapılandırılmamışsa, bu API endpoint'ine erişim sınırlı veya mümkün olmayabilir.

3. Meta Tagları ve HTML Kaynağı

Joomla sürüm bilgileri, bazen meta tagları ve HTML kaynak kodu içinde bulunabilir.

```auto
<meta name="generator" content="Joomla! - Open Source Content Management" />
```

Bu tür meta tagları, sitenin Joomla kullanıp kullanmadığını ve hangi sürümde olduğunu belirlemek için kullanılabilir.

4. 

readme.html

 Dosyası

Joomla'nın kök dizininde bulunan readme.html dosyası, genellikle sürüm bilgilerini içerir.

```auto
http://example.com/readme.html
```

Bu dosyaya erişerek Joomla sürümünü belirlemek mümkündür.

5. Administrator/Login Sayfası

Joomla'nın yönetim paneli giriş sayfası, sürüm bilgilerini barındırabilir.

```auto
http://example.com/administrator/
```

Sayfanın HTML kaynak kodunu inceleyerek sürüm bilgilerini tespit edebilirsiniz.

6. CSS ve JavaScript Dosyaları

Bazı CSS ve JavaScript dosyaları, sürüm bilgilerini içerebilir.

```auto
/media/system/js/mootools.js?version=1.6.0
```

Bu tür dosya isimleri ve query string'ler, Joomla sürümünü belirlemek için ipuçları sağlar.

### Çekirdek Bileşenler ve Modüller

Joomla'nın çekirdek bileşenleri ve modülleri, sitenin işlevselliği için önemlidir. Bu bileşenlerin tespiti ve sürüm bilgileri, potansiyel güvenlik açıklarını belirlemek için kullanılır.

1. Çekirdek Bileşenlerin Listesi

Joomla'da varsayılan olarak gelen bazı çekirdek bileşenler şunlardır:

- com_content
    
     (İçerik Yönetimi)
- com_users
    
     (Kullanıcı Yönetimi)
- com_weblinks
    
     (Web Bağlantıları)
- com_contact
    
     (İletişim Formları)
- com_newsfeeds
    
     (Haber Beslemeleri)

2. Bileşen Sürüm Tespiti

Çekirdek bileşenlerin sürümlerini tespit etmek için bileşen dosyalarını ve metadata bilgilerini inceleyebilirsiniz.

```auto
/components/com_content/content.xml
<version>1.6.0</version>
```

### Bilgi Toplama Yöntemleri

Manuel Yöntemler

Web tarayıcıları ve HTTP isteği inceleme araçları kullanarak manuel olarak bilgi toplama.

Araçlar:

- Tarayıcı Geliştirici Araçları (Dev Tools)
- Burp Suite
- Postman

Otomatik Araçlar

Bilgi toplama sürecini otomatikleştiren araçlar kullanmak, daha hızlı ve kapsamlı sonuçlar elde etmenizi sağlar.

Örnek Araçlar:

- JoomScan: Joomla sitelerini taramak ve güvenlik açıklarını tespit etmek için kullanılan bir araçtır.
    - joomscan --url http://example.com
        
- CMSMap: Çeşitli CMS'leri tarayan ve zafiyetleri tespit eden bir araçtır.
    - cmsmap -t joomla -u http://example.com
