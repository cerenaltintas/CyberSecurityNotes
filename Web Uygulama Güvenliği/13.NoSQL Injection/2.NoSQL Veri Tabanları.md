NoSQL veri tabanları, büyük veri ve yüksek erişilebilirlik gerektiren modern uygulamalar için ideal çözümler sunar. Geleneksel SQL veri tabanlarının sınırlamalarını aşmak için tasarlanmışlardır ve çeşitli veri modelleri ile farklı kullanım senaryolarına uyum sağlarlar. Bu bölümde, yaygın olarak kullanılan NoSQL veri tabanlarının türlerini ve özelliklerini inceleyeceğiz.

### NoSQL Veri Tabanlarının Türleri

NoSQL veri tabanları, veri modelleme yaklaşımlarına göre dört ana kategoriye ayrılır.

1. Belge Odaklı (Document-Oriented) Veri Tabanları

Belge odaklı veri tabanları, verileri JSON, BSON veya XML formatında belgeler halinde saklar. Her belge, dinamik olarak yapılandırılmış veri içerebilir ve koleksiyonlar halinde gruplandırılır.

Özellikler

- Esnek şema yapısı
- Karmaşık ve hiyerarşik veri yapılarını destekler
- Yüksek performanslı sorgulamalar ve indeksleme

Örnekler

- **MongoDB:** En yaygın kullanılan belge odaklı NoSQL veri tabanlarından biridir. JSON benzeri belgeler kullanarak veri depolar ve dinamik şema desteği sunar.
- **CouchDB:** Veri depolama ve sorgulama için JSON belgeleri kullanır. CouchDB, dağıtık veri yapıları ve çevrimdışı veri erişimi için tasarlanmıştır.

2. Anahtar-Değer (Key-Value) Veri Tabanları

Anahtar-değer veri tabanları, verileri anahtar-değer çiftleri halinde saklar. Her anahtar, benzersiz bir tanımlayıcıya sahiptir ve bu anahtar ile ilişkilendirilen değer, herhangi bir veri türünde olabilir.

Özellikler

- Basit veri modeli
- Yüksek hızlı veri erişimi
- Dağıtık sistemlerde yüksek ölçeklenebilirlik

Örnekler

- **Redis:** Bellek içi veri yapıları kullanarak yüksek performanslı anahtar-değer veri tabanı olarak çalışır. Veritabanı, gerçek zamanlı analizler ve önbellekleme için idealdir.
- **Riak:** Yüksek erişilebilirlik ve veri replikasyonu özellikleri ile bilinir. Riak, büyük ölçekli dağıtık sistemler için tasarlanmıştır.

3. Kolon Tabanlı (Column-Family) Veri Tabanları

Kolon tabanlı veri tabanları, verileri satırlar ve sütunlar halinde saklar. Ancak her satır, farklı sayıda ve türde sütun içerebilir ve bu sütunlar kolon aileleri olarak gruplanır.

Özellikler

- Yüksek yazma ve okuma performansı
- Büyük veri kümeleri için optimize edilmiştir
- Esnek veri modelleme

Örnekler

- **Cassandra:** Dağıtık ve ölçeklenebilir bir kolon tabanlı veri tabanıdır. Yüksek erişilebilirlik ve veri replikasyonu özellikleri ile bilinir.
- **HBase:** Apache Hadoop ekosisteminin bir parçası olarak, büyük veri işleme ve analiz için kullanılır. HBase, kolon tabanlı veri modeli ile yüksek verimli veri erişimi sağlar.

4. Graf (Graph) Veri Tabanları

Graf veri tabanları, verileri düğümler ve kenarlar şeklinde modelleyerek, nesneler arasındaki ilişkileri ve bağlantıları saklar. Bu veri tabanları, karmaşık ilişkisel verileri depolamak ve sorgulamak için idealdir.

Özellikler

- Karmaşık ilişkisel sorgular için optimize edilmiştir
- Doğrudan veri ilişkilerini modelleme yeteneği
- Esnek ve dinamik veri yapıları

Örnekler

- **Neo4j:** En popüler graf veri tabanlarından biridir. Neo4j, veri ilişkilerini doğrudan modelleyerek karmaşık ağ analizleri yapar.
- **ArangoDB:** Çoklu model veri tabanı olarak çalışır ve graf verilerini destekler. ArangoDB, hem belge hem de graf veri modellemeyi bir arada sunar.

### NoSQL Veri Tabanlarının Yaygın Kullanım Alanları

NoSQL veri tabanları, farklı kullanım senaryoları ve uygulama ihtiyaçlarına göre geniş bir yelpazede kullanılır.

1. Büyük Veri Analitiği

NoSQL veri tabanları, büyük veri kümelerini hızlı bir şekilde işlemek ve analiz etmek için idealdir. Örneğin, Cassandra ve HBase, büyük veri analizlerinde yaygın olarak kullanılır.

2. Gerçek Zamanlı Uygulamalar

Gerçek zamanlı veri işleme ve hızlı veri erişimi gerektiren uygulamalar için Redis ve MongoDB gibi NoSQL veri tabanları tercih edilir. Örneğin, sosyal medya platformları ve e-ticaret siteleri.

3. İçerik Yönetim Sistemleri

Belge odaklı veri tabanları, dinamik ve yapılandırılmamış içeriklerin yönetimi için idealdir. Örneğin, CouchDB ve MongoDB, içerik yönetim sistemlerinde yaygın olarak kullanılır.

4. Dağıtık Sistemler

NoSQL veri tabanları, dağıtık mimarilerde yüksek ölçeklenebilirlik ve erişilebilirlik sağlar. Örneğin, Riak ve Cassandra, dağıtık sistemlerde veri replikasyonu ve yük dengeleme için kullanılır.

### NoSQL Temel Kavramlar ve Operatörler

Temel Kavramlar

- **Document:** JSON veya BSON formatında veri saklayan belge.
- **Collection:** Belgelerin gruplandığı yapı.
- **Key-Value Pairs:** Anahtar-değer çiftleriyle veri saklama yöntemi.
- **Column Family:** Kolon bazlı veri saklama yöntemi.

Operatörler ve Kullanım Alanları

$eq (equal)

Eşitlik kontrolü yapar.

```auto
{ "field": { "$eq": value } }
```

$ne (not equal)

Eşit olmama kontrolü yapar.

```auto
{ "field": { "$ne": value } }
```

$gt (greater than)

Büyük olma kontrolü yapar.

```auto
{ "field": { "$gt": value } }
```

$gte (greater than or equal)

Büyük veya eşit olma kontrolü yapar.

```auto
{ "field": { "$gte": value } }
```

$lt (less than)

Küçük olma kontrolü yapar.

```auto
{ "field": { "$lt": value } }
```

$lte (less than or equal)

Küçük veya eşit olma kontrolü yapar.

```auto
{ "field": { "$lte": value } }
```

$in

Belirtilen değerlerden herhangi biriyle eşleşme kontrolü yapar.

```auto
{ "field": { "$in": [value1, value2, ...] } }
```

$nin (not in)

Belirtilen değerlerden hiçbiriyle eşleşmeme kontrolü yapar.

```auto
{ "field": { "$nin": [value1, value2, ...] } }
```

$exists

Alanın var olup olmadığını kontrol eder.

```auto
{ "field": { "$exists": true } }
```

$regex

Düzenli ifadeyle eşleşme kontrolü yapar.

```auto
{ "field": { "$regex": /pattern/ } }
```

### NoSQL Veri Tabanları Syntax

1. MongoDB

MongoDB, belge odaklı bir NoSQL veri tabanıdır ve verileri JSON benzeri belgeler halinde saklar. MongoDB'deki temel işlemler ve sözdizimi aşağıdaki gibidir.

Belge Ekleme (Insert)

```auto
db.collection.insertOne({ "name": "Alice", "age": 25 });
db.collection.insertMany([{ "name": "Bob", "age": 30 }, { "name": "Charlie", "age": 35 }]);
```

Belge Bulma (Find)

```auto
db.collection.find({ "name": "Alice" });
db.collection.find({ "age": { "$gt": 30 } });
```

Belge Güncelleme (Update)

```auto
db.collection.updateOne({ "name": "Alice" }, { "$set": { "age": 26 } });
db.collection.updateMany({ "age": { "$lt": 30 } }, { "$inc": { "age": 1 } });
```

Belge Silme (Delete)

```auto
db.collection.deleteOne({ "name": "Alice" });
db.collection.deleteMany({ "age": { "$gte": 30 } });
```

2. CouchDB

CouchDB, belge odaklı ve JSON formatında veri saklayan bir NoSQL veri tabanıdır. CouchDB'deki temel işlemler ve sözdizimi aşağıdaki gibidir.

#### Belge Ekleme (Insert)

```auto
PUT /database/document_id
{
  "name": "Alice",
  "age": 25
}
```

Belge Bulma (Find)

```auto
GET /database/document_id
```

Belge Güncelleme (Update)

```auto
PUT /database/document_id
{
  "_rev": "revision_id",
  "name": "Alice",
  "age": 26
}
```

Belge Silme (Delete)

```auto
DELETE /database/document_id?rev=revision_id
```

3. Redis

Redis, bellek içi bir anahtar-değer veri tabanıdır ve veri yapıları üzerinde hızlı işlemler sağlar. Redis'teki temel işlemler ve sözdizimi aşağıdaki gibidir.

Anahtar-Değer Çifti Ekleme (Set)

```auto
SET key value
```

Anahtar-Değer Çifti Alma (Get)

```auto
GET key
```

Liste Ekleme (List Push)

```auto
LPUSH mylist value
RPUSH mylist value
```

Liste Alma (List Get)

```auto
LRANGE mylist 0 -1
```

Set Ekleme (Set Add)

```auto
SADD myset value
```

Set Alma (Set Members)

```auto
SMEMBERS myset
```

Hash Ekleme (Hash Set)

```auto
HSET myhash field value
```

Hash Alma (Hash Get)

```auto
HGET myhash field
```
