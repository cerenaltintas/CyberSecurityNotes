Time based NoSQL injection, saldırganların zaman gecikmeleri (delays) kullanarak veri tabanının davranışını manipüle ettiği ve veri tabanındaki hassas bilgileri çıkardığı bir saldırı türüdür. Bu tür saldırılar, zaman tabanlı koşullar kullanılarak sorguların nasıl çalıştığını ve veri tabanının nasıl tepki verdiğini anlamak için kullanılır.

Time based injection saldırıları, veri tabanının yanıt süresini analiz ederek veri sızdırma veya sistem bilgilerini elde etme yöntemidir. Bu saldırılar, belirli sorguların veri tabanına gönderilmesi ve yanıt sürelerinin ölçülmesiyle gerçekleştirilir. Yanıt sürelerindeki değişiklikler, veri tabanının içeriği veya belirli koşullar hakkında bilgi verir.

**Örnek:** MongoDB'de Time Based Injection

Aşağıdaki örnekte, MongoDB'de timing based injection saldırısının nasıl gerçekleştirilebileceğini göreceğiz.

```auto
// Güvenlik açığı bulunan sorgu
db.users.find({ "username": username, "password": password });
```

Bu sorgu, kullanıcı adı ve şifresini kontrol etmek için kullanılır. Saldırgan,

username

veya

password

alanına zararlı bir girdi enjekte ederek sorguyu manipüle edebilir.

```auto
// Zararlı girdi
username = "admin";
password = { "$where": "sleep(1000) || this.password == 'password123'" };

// Manipüle edilmiş sorgu
db.users.find({ "username": "admin", "password": { "$where": "sleep(1000) || this.password == 'password123'" } });
```

Bu durumda,

password

alanına

$where

operatörü enjekte edilmiştir. Bu operatör, password alanının

password123

olup olmadığını kontrol ederken 1000 milisaniye (1 saniye) gecikme ekler. **Sorgu 1 saniye gecikirse, şifrenin doğru olduğunu gösterir.** Saldırganlar bu şekilde parola hakkında bir çıkarım yapabilir.
