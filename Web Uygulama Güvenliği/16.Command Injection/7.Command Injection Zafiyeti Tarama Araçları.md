### Commix

![](https://storage.hackviser.com/file/hackviser-prod/trainings/sections/images/438b344d-e799-4664-862b-ca3d422e1fc2/commix-f304ce869.webp)

Commix (Command Injection Exploiter), web uygulamalarındaki Command Injection zafiyetlerini tespit edip istismar etmeye yarayan otomatik bir araçtır. Güvenlik araştırmacıları ve sızma testi uzmanları için oldukça faydalıdır.

Commix Özellikleri

1. **Tespit ve İstismar**: Commix, web uygulamalarındaki command injection açıklarını otomatik olarak tespit eder ve istismar eder.
2. **Çeşitli Enjeksiyon Teknikleri**: Klasik, kör (blind) ve zaman tabanlı enjeksiyon tekniklerini destekler.
3. **Özelleştirme ve Gelişmiş Özellikler**: Geniş özelleştirme seçenekleri sunar ve OOB (Out-of-Band) enjeksiyon, manipülasyon ve payload kodlama gibi gelişmiş özellikler içerir.
4. **Uyumluluk**: Unix-benzeri ve Windows sistemlerinde çalışır ve birçok web sunucusu ve framework'ü destekler.

Kurulum

Commix, Git kullanarak kolayca kurulabilir. İşte adım adım kurulum rehberi:

1. **Depoyu Klonlayın**:
    
    ```auto
    git clone https://github.com/commixproject/commix.git commix
    ```
    
2. **Dizine Geçiş Yapın**:
    
    ```auto
    cd commix
    ```
    
3. **Aracı Çalıştırın**:
    
    ```auto
    python commix.py
    ```
    

Temel Kullanım

Commix, hedef web uygulamasının URL'sine ve isteğe bağlı olarak potansiyel olarak savunmasız bir parametreye ihtiyaç duyar. İşte Commix'in kullanımına dair bir örnek:

```auto
python commix.py <params>
```

Parametre Seçenekleri

- **URL Belirtme**:
    
    ```auto
    --url="http://example.com/index.php"
    ```
    
- **Veri Parametresi Belirtme**:
    
    ```auto
    --data="command=test"
    ```
    
- **İstek Yöntemi**:
    
    ```auto
    --method=POST
    ```
