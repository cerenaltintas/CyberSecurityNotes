SQL enjeksiyonu, kötü niyetli kişilerin bir web uygulamasının veri tabanına yetkisiz erişim sağlamak, veri tabanındaki verileri değiştirmek veya silmek için kullandıkları bir saldırı türüdür. Bu saldırıda, saldırgan, web uygulamasının veri tabanı ile iletişim kurmak için kullandığı SQL sorgularına zararlı kodlar ekler.

Web uygulamaları, kullanıcıların girdiği verileri (örneğin, kullanıcı adı, parola, arama terimi) kullanarak veritabanından bilgi almak için SQL sorguları oluşturur. Saldırgan, bu veri giriş alanlarına zararlı SQL kodları girerek, web uygulamasının oluşturduğu SQL sorgusunun yapısını değiştirir ve beklenmeyen işlemler gerçekleştirmesini sağlar.

Normal bir kullanıcı adı ve parola giriş formu düşünelim. Bu form, kullanıcıdan aldığı bilgileri kullanarak aşağıdaki gibi bir SQL sorgusu oluşturur:

```auto
SELECT * FROM users WHERE username = 'user' AND password = 'pass'
```

Ancak, saldırgan kullanıcı adı alanına

' OR 1=1 --

gibi bir değer girerse, oluşturulan SQL sorgusu şu şekilde değişir:

```auto
SELECT * FROM users WHERE username = '' OR 1=1 --' AND password = 'pass'
```

Bu durumda,

1=1

ifadesi her zaman doğru olacağından, sorgu tüm kullanıcı kayıtlarını döndürür ve saldırgan herhangi bir parola girmeden sisteme giriş yapabilir.
