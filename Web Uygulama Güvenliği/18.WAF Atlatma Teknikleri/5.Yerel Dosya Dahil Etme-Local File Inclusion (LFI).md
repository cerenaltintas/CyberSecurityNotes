LFI, bir web uygulamasındaki güvenlik açığından yararlanarak, saldırganın sunucudaki dosyalara erişmesine, okumasına veya çalıştırmasına olanak tanıyan bir tür web saldırısıdır. Bu açığın temel nedeni, web uygulamasının kullanıcı tarafından girilen dosya adlarını veya yollarını doğru şekilde kontrol etmemesidir.

Web uygulamaları genellikle dinamik içerik oluşturmak için dosyaları içerir. Örneğin, bir web sitesindeki haberler veya blog yazıları genellikle ayrı dosyalarda saklanır ve kullanıcı tarafından istendiğinde bu dosyalar web sayfasına dahil edilir.

LFI saldırısı, saldırganın bu dosya dahil etme mekanizmasını kötüye kullanarak, web uygulamasını istemediği veya zararlı bir dosyayı dahil etmeye zorlamasıdır. Bu, saldırganın sunucudaki hassas dosyalara erişmesine, web uygulamasının kodunu değiştirmesine veya sunucu üzerinde zararlı kod çalıştırmasına neden olabilir.

- **Hassas Dosyalara Erişim:** Saldırgan, 
    
    /etc/passwd
    
     gibi sistem dosyalarına erişerek kullanıcı adları ve parola hash'leri gibi hassas bilgileri ele geçirebilir.
- **Zararlı Kod Çalıştırma:** Saldırgan, sunucuda zararlı bir PHP betiği oluşturup, web uygulamasını bu betiği çalıştırması için kandırabilir. Bu, sunucu üzerinde tam kontrol sağlamaya kadar gidebilir.

Örneğin DVWA üzerinde çalışan kaynak kodu aşağıdaki gibidir

```auto
<?php

define( 'DVWA_WEB_PAGE_TO_ROOT', '../../' );
require_once DVWA_WEB_PAGE_TO_ROOT . 'dvwa/includes/dvwaPage.inc.php';

dvwaPageStartup( array( 'authenticated' ) );

$page = dvwaPageNewGrab();
$page[ 'title' ]   = 'Vulnerability: File Inclusion' . $page[ 'title_separator' ].$page[ 'title' ];
$page[ 'page_id' ] = 'fi';
$page[ 'help_button' ]   = 'fi';
$page[ 'source_button' ] = 'fi';

dvwaDatabaseConnect();

$vulnerabilityFile = '';
switch( dvwaSecurityLevelGet() ) {
        case 'low':
                $vulnerabilityFile = 'low.php';
                break;
        case 'medium':
                $vulnerabilityFile = 'medium.php';
                break;
        case 'high':
                $vulnerabilityFile = 'high.php';
                break;
        default:
                $vulnerabilityFile = 'impossible.php';
                break;
}

require_once DVWA_WEB_PAGE_TO_ROOT . "vulnerabilities/fi/source/{$vulnerabilityFile}";

// if( count( $_GET ) )
if( isset( $file ) )
        include( $file );
else {
        header( 'Location:?page=include.php' );
        exit;
}

dvwaHtmlEcho( $page );

?>
```

```auto
<?php

// The page we wish to display
$file = $_GET[ 'page' ];

?>
```
