XSS, web uygulamalarındaki bir güvenlik açığından yararlanılarak, saldırganın başka bir kullanıcının tarayıcısında kötü niyetli kodlar çalıştırmasına olanak tanıyan bir saldırıdır. Bu kodlar genellikle JavaScript formunda olur ve kullanıcının oturum çerezlerini çalma, web sitesinin görünümünü değiştirme veya kullanıcının bilgisayarına zararlı yazılımlar indirme gibi çeşitli amaçlar için kullanılabilir.

XSS Saldırı Türleri:

- Yansıtılan XSS (Reflected XSS): Saldırgan, zararlı kodu bir URL veya form verisi aracılığıyla web uygulamasına gönderir. Uygulama, bu kodu doğru bir şekilde filtrelemeden veya temizlemeden kullanıcının tarayıcısına geri gönderir ve bu kod kullanıcının tarayıcısında çalışır.
- Kalıcı XSS (Stored XSS): Saldırgan, zararlı kodu web uygulamasının veritabanına veya diğer bir depolama alanına kalıcı olarak yerleştirir. Bu kod, diğer kullanıcılar tarafından görüntülenen sayfalara dahil edilir ve bu kullanıcıların tarayıcısında çalışır.
- DOM Temelli XSS (DOM Based XSS): Saldırgan, zararlı kodu istemci tarafındaki JavaScript kodu aracılığıyla web sayfasının DOM (Document Object Model) yapısına enjekte eder. Bu kod, kullanıcı etkileşimi veya sayfa yüklenmesi sırasında tetiklenir ve kullanıcının tarayıcısında çalışır.

XSS Saldırılarının Sonuçları:

- Oturum Çerezlerinin Çalınması: Saldırgan, kullanıcının oturum çerezlerini çalarak, kullanıcının hesabını ele geçirebilir ve kullanıcının kimliğine bürünebilir.
- Zararlı Yazılım İndirme: Saldırgan, kullanıcının bilgisayarına zararlı yazılımlar indirebilir.
- Veri Değiştirme veya Silme: Saldırgan, web uygulamasındaki verileri değiştirebilir veya silebilir.
- Kullanıcının Tarayıcısını Kontrol Etme: Saldırgan, kullanıcının tarayıcısını kontrol altına alarak, kullanıcının adına farklı eylemler gerçekleştirebilir.

Örneğin DVWA üzerinde çalışan Reflected XSS kaynak kodu aşağıdaki gibidir

```auto
<?php

header ("X-XSS-Protection: 0");

// Is there any input?
if( array_key_exists( "name", $_GET ) && $_GET[ 'name' ] != NULL ) {
        // Feedback for end user
        $html .= '<pre>Hello ' . $_GET[ 'name' ] . '</pre>';
}

?>
```

```auto
<object onafterscriptexecute=confirm(0)>
<object onbeforescriptexecute=confirm(0)>
<img src='1' onerror\x00=alert(0) />
<img src='1' onerror\x0b=alert(0) />
<img src='1' onerror/=alert(0) />
...
```

Örneğin

```auto
<object onafterscriptexecute=confirm(0)>
```

Yaparsak WAFı atlattığını görebiliriz.
